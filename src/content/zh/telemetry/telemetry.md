# 使用统计 {#usage-stats}

> Harbor 收集哪些数据，以及如何选择退出。

Harbor 收集有限的使用遥测数据，用于提升可靠性并确定开发优先级。默认启用。

## 收集的数据 {#collected-data}

Harbor 发送两类事件：

| 事件                      | 数据                                                                                                                                                            |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `harbor.command_finished` | 运行时与平台、安装与启动来源、检测到的 AI Agent 标签、命令路径、标志名称、结果、持续时间以及作业 ID                                                              |
| `harbor.job_finished`     | 作业 ID、Agent 与模型、环境与资源、任务与试次数量、已启用功能、公开来源、结果、token 用量、成本、持续时间以及奖励                                                 |

## 不收集的数据 {#not-collected}

* 原始命令或作业配置
* 本地路径、私有仓库名称或自定义 registry 位置
* 任务指令、提示词或本地任务名称
* 环境变量、Agent 或环境 kwargs，或 MCP 配置
* 产物路径
* 异常消息或 traceback
* 用户名、电子邮件或账户身份

## 身份与投递 {#identity-and-delivery}

Harbor 会在用户配置目录中创建随机安装 ID。
该 ID 不来源于账户或机器身份。

事件在命令返回后由分离进程发送到 PostHog。
投递失败即丢弃。个人资料与 GeoIP 处理已禁用。

## 选择退出 {#opt-out}

```bash
HARBOR_TELEMETRY=off harbor run ...
```
