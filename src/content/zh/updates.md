# 同步日志 {#updates}

> 官网每有变动，这里单独记一笔：改了什么、中文站在哪一页。

Harbor 官方文档在 [docs.harborframework.com](https://docs.harborframework.com/) 持续更新。本站每天对照 GitHub `docs-mintlify` 的 blob SHA（与对照表同一套指纹）：

- **新增**：官网多了一页 → 日志写中文站将出现的路径（`/docs/...`）。
- **更新**：某一页 SHA 变了 → 日志写中文标题和本站位置，方便直接打开。
- **移除**：官网删页 → 日志标明，避免还链到旧译本。

顶栏「同步」始终指向本页最新一条。完整页级指纹在 [对照表](/docs/sitemap)。
